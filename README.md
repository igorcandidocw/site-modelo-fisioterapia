# Site modelo — Fisioterapia

Site estático (HTML, CSS e JavaScript puros) de uma fisioterapeuta fictícia, criado como modelo.

## Estrutura
- `index.html` — página principal
- `politica-de-privacidade.html` — política de privacidade
- `css/`, `js/`, `img/` — estilos, scripts e imagens otimizadas
- `robots.txt`, `sitemap.xml`, `llms.txt` — SEO

## Publicar na Vercel
Importe o repositório na Vercel com o preset **Other**, sem comando de build e com o diretório raiz `./`.
